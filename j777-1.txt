請仔細檢查我這個 HTML/JavaScript 編輯器中的「本地資源暫存區」功能。

目前問題：

我在「本地資源暫存區」加入了音效檔，例如：

bgm01.mp3
shake01.mp3
flip01.mp3
win01.mp3

而且畫面上顯示本地資源已加入、已套用。

我的使用程式碼是：

const sounds = {
  bgm: new Audio('bgm01.mp3'),
  shake: new Audio('shake01.mp3'),
  flip: new Audio('flip01.mp3'),
  win: new Audio('win01.mp3')
};

但是執行預覽後完全沒有音效。

請注意：

1. 不要把問題簡單歸因於瀏覽器 autoplay。
2. 我的測試程式會在使用者點擊按鈕後呼叫 play()，所以請不要把「瀏覽器阻擋自動播放」當成主要原因。
3. 請從我目前的「localResourceMap → Blob URL → iframe → interceptor → Audio」整條流程檢查。
4. 不要破壞目前 img、video、audio、source、script、link、iframe、object、embed 以及 CSS url() 的本地資源功能。
5. 不要移除目前的本地資源暫存功能。
6. 不要改成讓使用者每次都必須手動輸入 Blob URL。
7. 不要要求使用者修改自己的遊戲程式碼。
8. 最終目標是讓使用者可以直接寫：
   
   new Audio('bgm01.mp3')

   或：

   const audio = new Audio('./bgm01.mp3');

   或：

   audio.src = 'bgm01.mp3';

   或：

   audio.src = './bgm01.mp3';

   都可以正確找到「本地資源暫存區」裡的音效。

==================================================
一、請先檢查目前 localResourceMap
==================================================

目前資源加入方式：

const key = normalizeLocalResourceKey(file.name);

localResourceMap.set(key, {
  file,
  url,
  size: file.size,
  type: file.type || '',
  name: file.name
});

請確認：

bgm01.mp3

會被儲存成：

bgm01.mp3

而：

./bgm01.mp3

也可以透過 normalizeLocalResourceKey() 找到：

bgm01.mp3

不要改壞目前的 key normalization。

==================================================
二、加強 resolveLocalResourceUrl()
==================================================

請讓：

resolveLocalResourceUrl('bgm01.mp3')

resolveLocalResourceUrl('./bgm01.mp3')

resolveLocalResourceUrl('/bgm01.mp3')

resolveLocalResourceUrl('folder/bgm01.mp3')

都能正常處理。

尤其要注意 URL 中：

?
#

以及：

../
./

的處理。

如果找不到資源，不要靜默失敗。

請增加 console.warn，例如：

如果成功找到：

[LocalResource] resolved: bgm01.mp3 -> blob:...

目前 createLocalResourceInterceptorScript() 裡面有：
