【三、使用 Map 管理本地資源】
==================================================

請建立獨立的 Map，例如：

const localResourceMap = new Map();

Map 的 key 必須是檔案名稱。

例如：

localResourceMap.set("logo.png", {
    file: file,
    url: blobUrl,
    size: file.size,
    type: file.type,
    name: file.name
});

使用：

URL.createObjectURL(file)

建立 Blob URL。

例如：

const blobUrl = URL.createObjectURL(file);

【七、iframe 與父頁面溝通】
==================================================

由於 Blob URL 建立在父頁面，所以 iframe 需要能取得對應資料。

請使用目前專案已有的：

架構，或建立安全、簡潔的 parent → iframe 資源同步方式。

例如可以建立：

LOCAL_RESOURCE_MAP

訊息。

iframe 載入時由 parent 傳送目前所有資源：

{
    type: "LOCAL_RESOURCE_MAP",
    resources: {
        "logo.png": "blob:...",
        "bgm01.mp3": "blob:...",
        "data.json": "blob:..."
    }
}

iframe 端收到後建立自己的 Map。

不要把 File 物件直接序列化。

只傳 Blob URL 與檔名。
