請修正 createLocalResourceInterceptorScript()：

1. 最終傳給 document.write() 的 HTML 字串中，必須是真正的：
</script>

</script>

避免外層 HTML parser 提前結束 script。

請使用安全的字串組合方式，例如：

'</' + 'script>'

或：

'<script>' + code + '</' + 'script>'

<script>

</script>
